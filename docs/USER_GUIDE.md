# NEXUS 用户与配置手册 v0.4.9

## 1. 工作空间与布局

- 顶部栏目用于切换工作空间；每个工作空间拥有独立主题和板块布局。
- 点击“编辑布局”后可拖动板块标题栏、缩放、锁定、悬浮和选择一至三层层级。
- 编辑状态下，板块标题栏的栏目选择器可把板块移到其他工作空间；板块会自动使用目标工作空间主题。
- “添加板块”可直接指定目标栏目。布局自动保存；“恢复默认”只重置布局，不删除密钥、对话、计划或提醒。
- 右上角全屏按钮进入 Electron 原生无标题栏全屏，再次点击退出。

## 2. 模型、语音与搜索

入口：左上角品牌按钮或底部“系统设置” → “模型·语音·搜索”。

### 大模型 LLM

选择服务商后填写 Model ID、Endpoint ID、Base URL 和 API Key。豆包方舟必须填写 `ep-...` Endpoint ID；OpenAI-compatible 服务通常需要 Base URL、Model ID 和 API Key；Ollama/LM Studio 的 API Key 通常可留空。保存后点击该分类右上角测试按钮，只有收到真实服务响应才显示连接成功。

### 实时语音

负责麦克风全双工对话、实时打断、回复音频和声音形象。豆包 Seeduplex 使用固定 WebSocket 地址和协议版本，必须填写 Realtime API Key。

“声音形象 ID”只有这一处可编辑。保存后，实时对话和 TTS 都使用此 ID；眼睛按钮仅临时显示密钥，平常以星号遮罩。

点击“测试连接与声音形象”会建立真实 WebSocket 会话并校验 API Key、协议和 Voice ID。连接成功不等于麦克风权限已经授予；第一次对话仍需允许 Windows/macOS 麦克风权限。

### ASR 与 TTS

- ASR 把语音转为文字；根据服务商填写模型/资源、Base URL 和 Token。
- TTS 把文字转成声音；豆包需要 `X-Api-Resource-Id`，例如 `seed-tts-2.0`。
- TTS 不再单独保存第二个音色；当前音色来自“实时语音”中的声音形象 ID。
- 每个分类都有独立测试按钮，错误信息会指出缺失字段、鉴权、资源或网络问题。

### 搜索引擎

第一梯队按 Serper → Brave → Tavily → SearXNG 尝试；没有结果时使用 Bing、Jina、DuckDuckGo 兜底。可以同时配置多个 Key。SearXNG 必须填写带 `http://` 或 `https://` 的实例地址。

## 3. 对话、语音与中枢

- 点击语音核心开始/停止实时对话；用户重新说话时会停止当前播放并发送打断信号。
- 语音识别、用户文本和智能体回复写入同一对话历史；历史默认跟随最新消息到最下方。
- DeepSeek Harness 可使用“托管模式”由 NEXUS 自动启动，也可连接外部地址。
- Hermes Desktop 建议把 Gateway 填为 `auto`，NEXUS 会探测动态端口；连接状态只有收到真实健康响应才显示在线。
- Hermes 角色、能力、目录权限和审批策略在“智能体与权限”中配置并生成固定 `SKILL.md`。

## 4. 万年历、黄历、备忘和提醒

- 日历同屏显示阳历、农历与节日；点击某一天查看黄历宜忌、值日、冲煞和彭祖百忌。
- 在选中日期下填写标题、时间、分类和重复方式即可创建提醒。
- 分类包括一次性、生日、节日、纪念日和备忘。
- 重复方式包括一次、每天、每周、每月、每年按阳历、每年按农历。
- 日历提醒会同步显示在备忘录板块；从任一处删除会同步更新。
- 提醒由全局调度器检查，切换工作空间后仍然有效；软件需要处于运行状态，并获得系统通知权限。

## 5. 数据与密钥

Windows 用户数据默认位于：

```text
%APPDATA%\nexus-voice-console
```

主要内容包括 Electron Local Storage、Harness 配置、会话数据和加密密钥文件。API Key 经 Electron `safeStorage` 加密后写入 `secrets.json`，界面配置不会保存明文 Key。卸载程序默认保留此目录，升级安装只替换程序目录。

布局、主题和部分轻量数据保存在 Electron Local Storage；计划 MD、模块数据和 Harness 数据按界面所选目录或用户数据目录保存。备份时应退出程序后复制整个用户数据目录。

## 6. 独立模块

入口：“设置 → 独立模块”。模块文件扩展名为 `.nexus-module`，最大 2 MB，使用 UTF-8 JSON。上传同一 `manifest.id` 且版本更高的文件会原位更新，不需要读取主体项目。详细格式见 [独立模块开发说明](MODULE_SDK_GUIDE.md)。

## 7. 常见排查

- 测试按钮无反应：先保存当前表单，检查必填项和网络，再查看按钮下方状态文字。
- Key 显示“已安全保存”：表示密钥已写入系统加密存储；留空保存不会覆盖旧 Key。
- 语音能连接但不出声：检查声音形象 ID、TTS Resource ID、系统输出设备和麦克风权限。
- Hermes 离线：确认 Hermes Desktop 正在运行，Gateway 使用 `auto`，并允许本机回环连接。
- 提醒不弹出：确认软件正在运行、时间与系统时区正确，并允许系统通知。
- 升级提示进程占用：使用 v0.4.9 或更高版本安装器；它会只关闭 NEXUS 自身进程并保留用户数据。
